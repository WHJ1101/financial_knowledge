01

页头 Hero + 目录

Hero & Table of Contents
适用：文档开篇。.hero 放标题、一句话摘要与元信息徽章（日期/分支/技术栈/工时）；.toc 放章节导航，滚动时自动高亮当前章节。参见本文件顶部实例。

Hero 用衬线大标题（可用 <em> 给关键词上陶土色），下方 .meta 徽章横排。目录 .toc-grid 自适应多列，每项 .n 为章节序号。

结构示意
<header class="hero">
  <div class="kicker">眉标</div>
  <h1>主标题 <em>关键词</em></h1>
  <p class="lead">一句话摘要</p>
  <div class="meta"><span>徽章</span></div>
</header>

03

标签 / 提示 / 标签组

Tags, Callouts & Chips

行内标签 .tag

适用：表格单元格、状态标注、枚举值。五种色：teal / clay / gold / sage / gray。

t-teal 主色 t-clay 强调 t-gold 警示 t-sage 通过 t-gray 中性

提示块 .note

适用：三种语义。info（信息/说明）、warn（注意/风险）、key（关键约束/红线）。
note-info：一般说明、补充信息、设计取舍。
note-warn：需要注意的前置条件或潜在风险。
note-key：不可违反的关键约束、安全红线。

标签组 .chips

适用：范围枚举、白名单、包含/排除项。.yes 带对勾、.no 带叉。
普通枚举项 包含项 排除项
04

表格

Tables
适用：需求拆解、字段说明、错误码、对比矩阵。用 .tbl-wrap 包裹 table 以支持窄屏横向滚动；表头墨绿、行 hover 变色。
字段类型必填规则
session_idint64是正数，标识会话
statusint是枚举 1 2
remarkstring否最长 200 字符
05

代码 / SQL 块

Code & SQL Blocks
适用：DDL、接口 JSON、代码片段、伪代码。深色底 + 顶部窗口条（可写文件名/说明）。高亮 span 类：.k 关键字 · .s 字符串 · .t 类型/字段 · .n 数字 · .c 注释。
example.sql
CREATE TABLE demo (
    id BIGINT NOT NULL AUTO_INCREMENT,
    name VARCHAR(64) NOT NULL DEFAULT '',
    status TINYINT NOT NULL DEFAULT 0 COMMENT '0 none',
    PRIMARY KEY (id) -- 主键
);
response.json
{
  "error_code": 0,
  "error_msg": "success",
  "result": { "record_id": 123 }
}

清单 / 风险卡

Checklist & Risk Cards

适用：验收标准、自测项、上线 checklist。每项自带鼠尾草色对勾方框。
